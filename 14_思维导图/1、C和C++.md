# C与C++区别

- 【标准答案】C是面向过程编程语言，注重的是程序实现的逻辑，不利于程序的复用，C++是面向对象的编程语言，注重程序的整体设计，后期方便维护、优化管理、让一个功能能够得到尽快的复用，然后C++有**封装继承多态**三大特性

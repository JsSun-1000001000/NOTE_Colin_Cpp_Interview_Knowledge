## 右值引用

**左值：**
- 可以出现在 =赋值 左边和右边的值，有名字，可以取地址
**右值：**
- 只可以出现在 =赋值 右边的值，没有名字，不可以取地址
**纯右值：**
- 运算表达式产生的临时变量、不和对象关联的原始字面量、非引用返回的临时变量、lambda表达式等都是纯右值
**将亡值：**
- 可以理解为即将销毁的值
**左值引用：**
- 对左值进行引用的类型
**右值引用：**
- 对右值进行引用的类型
**移动语义：**
- 转移资源所有权，类似于转让或者资源窃取的意思，对于那块资源，转为自己所拥有，别人不再拥有也不会再使用
**完美转发：**
- 可以写一个接受任意实参的函数模板，并转发到其他函数，目标函数会收到与转发函数完全相同的实参

## 右值引用

左值引用、右值引用、常引用
### 常引用

`const int &i = 10;` 10 是`const int`
### 右值引用

`r-ref rvalue reference`
用&&符号引用右值（也可以移动左值）

```cpp
Data data;
Data& data1 = data;//ok
Data& data1 = Data();//not compile
Data&& data2 = Data();//ok
Data&& data2 = data;//not compile
Data&& data2 = std::move(data);//ok
```

==**右值引用是左值？？？？**==

- 左值引用变量data1在初始化时，不能绑定右值Data()
- 右值引用变量data2在初始化时，不能绑定左值data
- 但可以通过move将左值转为右值
- 右值引用变量data2被初始化后，在作用域内是左值

**常引用和右值引用都能接受右值的绑定，有什么区别？**
- 通过右值引用/常引用初始化的右值，都可以将和生命周期扩展lifetime extension到绑定该右值的引用的生命周期
- 初始化时绑定了右值后，右值引用可以修改引用的右值，而常引用不能修改
- 都能接受右值和常量

```cpp
const Data& data1 = Data();//ok extend lifetime
data1.modify();//nope compile const
Data&& data2 = Data();//ok extend lifetime
data2.modify();//ok non-const
```
**使用场合：**
- 可以用于传参：`test(const Data& );test(Data&&)`
### move的理解

move
- move 本身不移动任何东西
- 左值强制转换成右值
- 从而可以调用对象的==移动构造函数或者移动赋值运算符==，将==管理的资源（如动态分配的内存）进行转移==
- 配合着移动构造和移动赋值对资源进行转移

### 什么是移动构造和移动赋值运算符函数

为了支持转移语句，C++11特意实现了移动构造和移动赋值运算符函数。首先他们与普通的拷贝构造函数和赋值操作符函数的区别就是
- 他们==接受右值引用==作为参数
- 其次就是==函数内部的实现是完成空间的转移==，而==非深拷贝==
- 他们是==系统默认生成的==，C++11就支持，无需自己实现

**右值引用都有什么用？**
除了上面提到的==延长常量对象生命周期==外，还包括：
- 为了==实现转移语义==和==完美转发==，消除两个对象交互时不必要的对象拷贝
- 能够更简洁明了地定义泛型函数（==**更准确的传参和调用函数——说就说这个前头那个什么勾巴玩意**==）
- 右值引用是用来支持转移语义的。转移语义可以将资源（堆、系统对象等）从一个对象转移到另一个对象，这样能够减少不必要的临时对象的创建、拷贝以及销毁，能够大幅度提高C++应用程序的性能
- 临时对象的维护（创建和销毁）对性能有严重影响。
- 转移语义适合拷贝语义相对的，可以类比文件的剪切和拷贝，当我们将文件从一个目录拷贝到另一个目录时，速度比剪切慢很多

**右值引用的用法举例：** 没听懂。。。
- vector，如果需要创建vector临时变量或者从函数中返回vector，只能通过创建一个新的并拷贝所有存于右值中的数据来存储数据。之后这个临时变量vector则会被销毁，同时删除其包含的数据
- 有了右值引用，一个参数为指向某个vector的右值引用的vector的转移构造器就能够简单地将该右值中C式数组的指针复制到新的vector，然后将该右值清空。这里没有数组拷贝，并且销毁被清空的右值也不会销毁保存数据的内存。返回vector的函数现在只需要返回一个vector<>&&
- 如果vector没有转移构造器，那么结果会像以前一样：用vector<>&参数 调用它的拷贝构造器。如果vector确实具有转移构造器，那么转移构造器就会被调用，从而避免大量的内存分配。

**右值引用可以实现精确传递**
- 精确传递适用于这样的场景：需要将一组参数原封不动的传递给另一个参数
- 精确传递就是在参数传递的过程中，所有这些属性和参数值都不能改变
在泛型函数中，这样的需求非常普遍

常引用比较烦人
```cpp
template <typename T>
void forward_value(const T& val){
	process_value(val);
}
template <typename T>
void forward_value(T& val){
	process_value(val);
}
int a = 0;
const int & b = 1;
forward_value(a);//int&
forward_value(b);//const int&
forward_value(2);//const int&
template <typename T>
void forward_value(T&& val){
	process_value(val);
}
int a = 0;
const int & b = 1;
forward_value(a);//int&
forward_value(b);//const int&
forward_value(2);//int&&
```

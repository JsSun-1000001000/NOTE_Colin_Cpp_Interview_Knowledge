## 拷贝构造什么时候调用？

已经存在的给还没存在的对象初始化的时候会用，分三种情况：

1. 利用对象来初始化另一个对象
2. 一个函数的参数是一个对象，传参的时候
3. 一个函数的返回值是一个对象，函数返回的时候

**==拷贝构造有几种写法？==**
`A a1; A a2(a1);`
参数是一个该类的对象，实参是一个对象，形参是一个对象的引用
`A a1; A a2 = a1;`
拿一个对象给另一个对象赋值，就是初始化

**==为什么拷贝构造的参数不是一个类对象，而是一个对象的引用？`A(const A & a)`==**
- 不能去掉`&`，如果没有引用，就会变成值传递，值传递时会创建一个新对象，创建新对象会调用拷贝构造函数，调用拷贝构造函数还通过值传递对象，触发嵌套，无限循环下去；
- 引用不会创建新对象，而是指向现有对象的内存位置。

## 虚析构 virtual

虚析构能解决——==父类指针指向子类对象的问题==，回收父类指针的时候，如果没有虚析构，就按照父类的析构函数析构，子类就有一部分空间没有被回收（不认识子类）产生==内存泄漏问题==。（父类不是虚析构）

如果虚析构，就执行多态，==先调用子类析构，后调用父类析构==；因为回收子类空间的时候看到父类空间，连带着一起回收。（父类是虚析构）

父类指针 = 子类对象；delete 父类指针；

## static 关键字 修饰？

类内的成员属性：不依赖对象，类共用的，不可以被继承，类外初始化，不能在头文件初始化（会引发重定义问题）要在源文件初始化

类内的函数：没有this指针，可以不依赖对象调用，类共用的，不可以声明为虚函数，不能直接调用类中的非静态成员，可以利用对象调用。

修饰变量，对象：仅此文件有效，其他文件看不到

类外的函数：仅此文件有效，其他文件看不到

**全局变量和静态变量**
- 修饰全局，是全局静态变量，生命周期到程序退出时结束，存在全局区
- 修饰局部，是局部静态变量，生命周期到程序退出时结束，存在全局区（单例的时候用）
- 无论是全局还是局部静态变量，都是初始化一次，没有初始化默认为0

## friend 关键字 友元

```cpp
class A; void test();
class B{
	private:
	void privateFun();
	friend class A;
	friend void test();
	int a;
}
class A{
	public:
	void fun(){ B b;b.privateFun();}
	void test(){
		B b;
		b.privateFun();
	}
}
```
`friend class A;` 申请友元类，允许A使用B中的保护和私有
`friend void test();` 申请友元函数，允许该函数使用类B中保护和私有

友元函数不是类里面的函数，友元类也不归属于当前所在的类，所以不能直接使用类的成员，可以通过对象来使用成员

优缺点：
- 访问使用保护和私有，使用更方便；但是能写get函数尽量用get函数，友元类无法指定，都能用（破坏封装安全性差——不建议）

==**友元是不可以被继承的！**==

### 多态是什么？

相同行为方式导致不同行为结果
### 多态有哪些种？

静态多态 和 动态多态
- 静态多态：在==编译期==确定（执行什么函数），可以==通过函数重载，函数模板来实现==静态多态（两种静态多态）
- 动态多态：在==运行时==确定（运行时多态），通过==继承和虚函数==实现动态多态，动态体现在

### 多态的实现（底层机制）

动态多态的时候，需要去对象的前四个字节里拿虚指针，里面装的虚函数表（Virtual Table—vbtl）的入口地址，在运行后才会有虚表，会加载到内存里，创建的对象才会能找到虚指针拿到虚表

静态多态在编译时，就写好函数指针地址了。

**虚指针**——指向虚函数列表的指针，虚函数是==对象的前四个字节（有的编译器有差别）==，通过提取前四个字节，就能找到虚函数数组的入口点

**对象**——物理内存

**动态多态的具体实现过程？**
- 父类要有虚函数，父类就有一个虚函数表
- 子类继承父类，子类就有一个虚函数表——若子类重写虚函数就会覆盖虚函数表里面的虚函数地址
- 准备工作完了，定义子类对象，子类对象前4个字节就会有一个虚指针，虚指针指向虚函数表，父类指针指向子类对象
- 父类指针调用虚函数，就会根据子类对象的前四个字节，得到虚指针，进而得到虚函数表的入口地址，通过遍历虚函数表，找到对应的虚函数并调用，从而完成多态

**C里实现多态？**
- 通过结构体和指针

**当调用虚函数/普通函数的时候，怎么确定是调父类的还是调子类的？**
- 首先看调用的是不是虚函数，是虚函数，看对象的虚函数表有没有重写；是普通函数，看指针类型是父类还是子类的，到相应的类型里面执行

**虚函数多态——可以利用引用来实现**

```cpp
B b;
A & a = b;
a.fun2();//执行虚函数多态
```

**虚函数优缺点**
**优点：**
- 可以代码不变，功能可变，具有良好的拓展和复用
**缺点：**
- 空间消耗，运行效率相对低一些，破坏封装
- 虚函数多态没有办法调用子类特有的虚函数

## 重载和重写

**重载：**
- C++中具有重载的功能
**多个函数重载：**
- ==相同作用域下，==函数名相同，==参数列表不同==（个数或者类型，或者都不同），这些函数我们说关系是重载的，对返回值没有限制
**重写（覆盖）：**
- 父类和子类之间的虚函数，要求==函数名、参数列表（个数和类型），返回值都要相同==

override会检查一下有没有重写

智能指针——万能皆可对象，指针封装->类 构造 析构->回收指针所指向的空间 自动回收空间

==**四个智能指针：`auto_ptr; unique_ptr; shared_ptr; weak_ptr`**==

## auto_ptr

小例子：
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <memory>

using namespace std;

class A{
public:
	AAAA(const string str){
		s=str;
		cout<<"AAAA:"<<s<<endl;
	}	
	~AAAA(){
		cout<<"~AAAA"<<endl;
	}
	void say(){
		cout<<"Say:"<<s<<endl;
	}
private:
	string s;
};

```
### auto_ptr 创建对象
```cpp
auto_ptr<AAAA> ap1(new AAAA("auto-ptr"));
auto_ptr<AAAA> ap2;
ap2.reset(new AAAA("auto_ptr2"));
auto_ptr<AAAA> ap3;
ap3 = ap1;
```
### auto_ptr使用对象
```cpp
ap3.get()->say();
ap3->say();
```
### auto_ptr主动回收对象
```cpp
ap3.reset();//析构
ap3.release();
```
### auto_ptr存在的问题

使用交出的太随意了，交出后，原指针为空，会失效，再调用会出问题
```cpp
ap1->say();
//ap1析构不会有问题
```


RAII思想——Resource Acquisition Is Initialization

智能指针——万能皆可对象，指针封装->类 构造 析构->回收指针所指向的空间 自动回收空间

==**四个智能指针：`auto_ptr; unique_ptr; shared_ptr; weak_ptr`**==

## auto_ptr

小例子：
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <memory>

using namespace std;

class A{
public:
	AAAA(const string str){
		s=str;
		cout<<"AAAA:"<<s<<endl;
	}	
	~AAAA(){
		cout<<"~AAAA"<<endl;
	}
	void say(){
		cout<<"Say:"<<s<<endl;
	}
private:
	string s;
};

```
### auto_ptr 创建对象
```cpp
auto_ptr<AAAA> ap1(new AAAA("auto-ptr"));
auto_ptr<AAAA> ap2;
ap2.reset(new AAAA("auto_ptr2"));
auto_ptr<AAAA> ap3;
ap3 = ap1;
```
### auto_ptr使用对象
```cpp
ap3.get()->say();
ap3->say();
```
### auto_ptr主动回收对象
```cpp
ap3.reset();//析构
ap3.release();
```
### auto_ptr存在的问题

使用交出的太随意了，交出后，原指针为空，会失效，再调用会出问题
```cpp
ap1->say();
//ap1析构不会有问题
```
## unique_ptr——唯一所有权智能指针

### 创建方式——相同
```cpp
unique_ptr<AAAA> up1(new AAAA("unique_ptr"));
unique_ptr<AAAA> up2;
up2.reset(new AAAA("unique_ptr2"));
```
### 使用权传递
```cpp
unique_ptr<AAAA> up3;
up3 = std::move(up1);//避免重复资源
```

**C++11 unique_ptr 用于替代废弃的 auto_ptr， 使用权传递的方式要求更严格，不可以直接赋值**

## shared_ptr 共享所有权智能指针

类似于文件系统的 引用计数

- 多个指针指向同一个堆空间，通过引用计数（use_counts），来记录所有权的指针个数
- 当引用计数为0时，回收这个堆空间
### 定义对象
```cpp
shared_ptr<AAAA> sp1(new AAAA("shared_ptr1"));
shared_ptr<AAAA> sp1 = shared_ptr<AAAA> (new AAAA("shared_ptr1"));

shared_ptr<AAAA> sp2;
sp2.reset(new AAAA("shared_ptr2"));

shared_ptr<AAAA> sp3;
sp3 = make_shared<AAAA>("shared_ptr3");
{
	shared_ptr<AAAA> sp4;
	sp4 = sp3;//指向同一个 共享
	cout<<sp4.use_count()<<endl;
}
//使用sp3.get()->say(); sp3->say();
sp3.use_count()//查看引用计数 主动挥手空间sp3.reset()
```

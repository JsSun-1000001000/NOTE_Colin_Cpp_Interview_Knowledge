
## 结构体

struct node{

## 结构体字节对齐的问题

找一个最大的类型，然后每次申请都按照这个类型大小的整数倍

有一个排布的问题，局部也要对齐，所以会存在空格（比如 char short int）空格的内容就是cccc

步骤：
1. 找到对齐的单位——最大的类型
2. 每次申请对齐的单位空间，尽量填装
3. 局部也要满足字节对齐
==注意：char型数组，看成多个char型变量，数组空间必须连续==

```cpp
struct node{
	short s;
	char c[7];
	double d;
}
```
先来八字节装一个s，剩下6个装0-5，然后多一个放在新八字节里，然后空6个，再装一个d

![[结构体嵌套结构体的字节对齐.png]]
嵌套的结构体要拆开算，但是还要做区分，答案是：56

## 为什么结构体存储的时候要进行字节对齐操作？

- 程序按照字长从内存中读取数据，比如32位的机器，那么就是一次读取的32位
- 如果没有字节对齐，可能一个变量会分为两次读取，才能确定其数值
- 这是一种空间换时间的方式
- 很容易计算出成员的位置，便于访问成员变量
- 遵循字节对齐原则，可以在不同平台下，遵循相同的对齐规则，避免数据读写问题

## 文件io操作

**fopen**
方式：只读w，只写r，追加a，扩展+，二进制b，其中，
- w——只读
- r——没有就创建，有就清空文件
- a——没有就创建，有就从末尾接着写
- +——扩展配合wr使用
- b——以二进制的方式进行操作（还有按照字符串的方式操作）

**fclose**

**fread、fwrite**：传一个文件指针，文件放在缓冲区，中间两个参数，第二个是每次都多少，第三个是读多少次； 返回的是成功读取的次数

**fgetc、fputs**：以字符的形式获取和输入字符串

**fseek、ftell**：一个是跳转，一个是指明当前距离文件开始读了多少字节，记录文件流走到哪了

==获取文件的大小（不用库）==：先跳转到文件末尾，然后ftell返回距离文件开始有多少字节，这个就是文件的大小了

## 堆和栈的区别（理解）

栈区就是一块整体区域，用的时候切一块，不够就是栈溢出，系统自动回收

堆区申请的时候==有个链表，链表里是空闲空间的地址==，申请后，找一个合适的给我，剩下的再挂回去，用完回收挂回去

==堆区更灵活（链表），也比栈区大==，从效率上讲，栈快因为是整块的

生长方向：栈从高向低地址生长；堆从低向高地址生长

栈是自动分配自动释放；堆是手动申请手动释放

## malloc-free/new-delete区别对比

1. new/delete是C++的操作符，而malloc/free是C中的函数。
2. new做两件事，一是分配内存，二是调用类的构造函数；同样，delete会调用类的析构函数和释放内存。而malloc和free只是分配和释放内存。
3. new建立的是一个对象，而malloc分配的是一块内存；new建立的对象可以用成员函数访问，不需要直接访问它的地址空间；malloc分配的是一块内存区域，用指针访问，可以在里面移动指针；new出来的指针是带有类型信息的，而malloc返回的是void指针。
4. new/delete是保留字，不需要头文件支持；malloc/free需要头文件库函数支持。

## 1.5类型转换

两种：显示转换、隐式转换

显示：`a+(type)b` 

隐式：`int a = -5; unsigned int b = 2; if(a+b>1)true else false`
结果为真，将有符号数转换为无符号型，类型不变

```cpp
int a;
char b;//b = -1
a = b;//a = -1 位扩展
/*----------------------------------*/
char a;
int b;//b可以是a范围内的值，是几就是几/范围外就会截断
a = b;//
```

### 隐式类型转换解决方法

1. 赋值的过程 a=b a b类型不会变
2. 小类型=大类型 发生截断
3. 大类型=小类型 值保持不变

例：
char a; int b = 320;
a = b;
->小类型 = 大类型 
->a范围是-128到127，那么赋值会发生截断
->a = (char)b; 320为0x0140
->发生截断为0x40 即64
->简单处理为 a = 320%256 = 64

int a; char b; b = -1;
a = b;
->大类型 = 小类型 值保持不变
->a = (int)b;
->b为0xff a为0xffffffff
->保持不变 a为-1

==size_t 类型是无符号整型==

==`~`按位取反 操作32位 返回有符号整型==

```cpp
while(scanf("%d",&a)!=EOF){
}
```
- `printf("")`%d %c %u 无符号整型；%x 16进制数；%p地址；%s %f %ld %lf

## 1.7位运算

`<<`左移 补0；`>>`右移 符号位 类型有关，无符号类型右移一定补0；有符号类型符号位位1补1，符号位为0补0

`~`按位取反（包括符号位）

`^`异或不同为1，相同为0

判断是否是奇数，奇数bit0为1，用a&1判断是否为奇数， 但是不能写`a&1 == 0`因为`&`比`==`优先级低，==应该加括号==

`&` 置位为0 `|`置位为1

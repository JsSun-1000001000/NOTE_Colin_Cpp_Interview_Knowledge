## 函数与指针

为什么使用指针？

因为代码不能一直在一个函数中写，要使用函数封装，让一个函数不能太长，但是有一些量需要跨函数，那么就需要使用地址间接使用变量，因而出现指针。

### 值传递 地址传递？

值传递，是实参给形参赋值，如`fun(int a = b);`，因而形参的值发生改变，并不能影响实参。
地址传递，是将地址的值从实参传给形参，形参有地址，可以间接访问空间并改写地址所指空间。

### 数据结构中，为什么数组传参要传长度？

`void fun(int arr[], int len);`

因为数组在传参的时候，传递的是指向数组首元素的指针

因为`sizeof(arr);`此时arr是一个指针，无法知道数组总空间的大小，那么就不直到数组多长，有越界的危险。因为字符串是以`\0`结束，即使不传长度也是可以的，不过要遍历一次得到长度，不如传参效率高。

`void fun(int arr[],int len);`等价于 `void fun(int *arr,int len);`

因为传入数组名，也是数组首地址，是一个地址，也就是指针

## 函数指针

写法：
`void fun(int a, int b);`fun替换为`(*pfun)`那么后面这个就是函数指针

## 什么是回调函数？

sort函数，epoll线程池中高效涉及到了回调

==一般的写法是函数的参数是一个函数指针，在函数中通过函数指针调用函数，还有一种写法，是将函数的指针提前登记，在需要时执行，比如线程池的写法==

```cpp
void sort(int arr[], int nlen, bool(*lpfun)(int a,int b)){
	if(lpfun(arr[0],arr[1])){
		swap(arr[0],arr[1]);
	}
}
```

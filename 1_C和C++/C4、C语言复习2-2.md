## 数组

相同类型的元素，存储在连续的空间中，这种数据结构叫数组

`int a[] = { };`假设数组首地址0x10

1. a常量数组名 首元素地址即0x10 a++错误的
2. sizeof(a)数组空间大小 = 元素个数\*每个元素占空间
3. a首元素地址 类型 int* 指针+数 = 偏移多少个单位 指针+1->原地址+sizeof(指向的类型)
4. &a类型指向整个数组 加一偏移整个数组 数组指针->`int(*)[4]`

![[数组.png]]

例：
```cpp
int a[4]={1,2,3,4};//首地址0x10
int *p = (int*)&a;
int (*p1)[4] = &a;

*(p+1) //取出2
*(*(p1+1)-1) //取出4

char * p3 = (char*)&a;
*(p3+1)
```
![[数组例题.png]]

### 数组下标为什么从0开始，而不是习惯中的1？

`a[3] == *(a+3)`访问元素时通过“基地址 + 索引偏移量”计算实际地址。 从0开始，索引直接对应偏移量，简化了地址计算，提高了访问效率。

## 二维数组

每个元素都是一个一维数组的数组

`int a[3][10] = {}`首地址0x10

1. a数组名——首元素的地址 首元素是一个数组 a是一个数组指针，a的类型就是`int (*)[10]`，a是常量a++是错误的，sizeof(a)=整个数组所占空间的大小 = 120；a+1地址要移动多少字节？40
2. &a 代表整个数组的地址 类型`int(*)[3][10];` &a+1地址移动0x10+120
3. `a[0]`第一个元素的名字 也就是数组名，也就是这个`int [10]`数组的首元素地址，`a[0]`类型`int*`，a的类型就是`int(*)[10]`，`a[0]`——`*(a+0)`类型`int*`，`a[0]+1`移动4字节
4. `&a[0]` `a[0]`是数组，数组是`int[10]`与上面的一维数组中a与&a类似；`&a[0]`类型是`int(*)[10]`，`&a[0]+1`移动40字节

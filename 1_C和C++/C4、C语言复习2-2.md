## 预处理

头文件展开，宏定义替换，围绕带#的工作

防止头文件重复包含

c++相互包含？
`#pragma once`

宽字节和多字节切换
```cpp
#ifdef UNICODE
#define MessageBox MessageBoxW;
#else
#define MessageBox MessageBoxA;
#endif
```

空指针
```cpp
#ifdef __cplusplus
#define NULL 0
#else
#define NULL (void*)0
#endif
```

debug
```cpp
#define DEBUG1
#if DEBUG
...
#else
...
#endif
```

define 的字符串用法
```cpp
#define # 转换为字符串 ## 拼接

#define str(m) #m
#define RootPath "c:/path"
#define colin(a,b) a##b
 
```

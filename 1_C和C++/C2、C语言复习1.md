## 1.1变量和数据类型

变量本质上是内存的别名。
- 变量名：==字母 下划线 $ 开始==，后面跟字母、数字、下划线、$，==不能有空格==
- 不能定义为保留的关键字
```cpp
typedef int (*PFUN)(int ,int );

//PFUN 是类型，typedef是给类型起别名
//PFUN 是int(*)(int ,int )的别名
//PFUN是一个函数指针的类型别名，指向函数类型为int(*)(int,int)
```
太麻烦了 看不懂
C++11 进行了升级：
```cpp
using PFUN = int (*)(int ,int);
```

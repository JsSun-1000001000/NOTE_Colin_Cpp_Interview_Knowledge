
## 结构体

结构体是复合结构类型，可以存在多种属性

例：结构体变量初始化 i缺省为0
```cpp
struct node{
	short s;
	char c;
	int i;
	struct node* pnext;//c++不需要了
}node1 = {1,'a'};//结构体变量初始化 i缺省为0 node1变量
```

栈区申请空间有个默认值0xccccccc，就是哪个烫烫烫烫烫烫
堆区默认值cdcdcd，堆区回收后默认是feeeeeee

## 结构体字节对齐的问题

找一个最大的类型，然后每次申请都按照这个类型大小的整数倍

有一个排布的问题，局部也要对齐，所以会存在空格（比如 char short int）空格的内容就是cccc

步骤：
1. 找到对齐的单位——最大的类型
2. 每次申请对齐的单位空间，尽量填装
3. 局部也要满足字节对齐
==注意：char型数组，看成多个char型变量，数组空间必须连续==

```cpp
struct node{
	short s;
	char c[7];
	double d;
}
```
先来八字节装一个s，剩下6个装0-5，然后多一个放在新八字节里，然后空6个，再装一个d

![[结构体嵌套结构体的字节对齐.png]]
嵌套的结构体要拆开算，但是还要做区分，答案是：56

## 为什么结构体存储的时候要进行字节对齐操作？

- 程序按照字长从内存中读取数据，比如32位的机器，那么就是一次读取的32位
- 如果没有字节对齐，可能一个变量会分为两次读取，才能确定其数值
- 这是一种空间换时间的方式
- 很容易计算出成员的位置，便于访问成员变量
- 遵循字节对齐原则，可以在不同平台下，遵循相同的对齐规则，避免数据读写问题
